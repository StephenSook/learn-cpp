# learn-cpp

My C++ practice while working through the Udemy course "Beginning C++ Programming - From Beginner to Beyond" (Frank Mitropoulos), then data structures and algorithms. One folder per course section (`section-04`, `section-05`, ...); my first program is in `chapter-00`.

Build and run the open file in VS Code: **Cmd+Shift+B**.
Compiler: Apple clang, C++20, warnings on (`-Wall -Wextra -Wconversion -Wsign-conversion -pedantic-errors`).
